# Fixtures

Fixtures are executable product behavior, not passive data. Search embedded
Client Script/Server Script content by document name and code.

Preserve standard ERP permissions and lifecycle behavior. A Custom DocPerm can
replace effective standard role coverage; audit all roles and use an
idempotent repair patch when required. For purchase changes, trace Purchase
Order, Receipt/return and Invoice/return plus stock, GL, supplier, tax and
selling-price effects. Server validation remains authoritative.

Validate every changed JSON file and syntax-check embedded code where
practical. Keep patches/fixtures ordered and update the owning bench skill.
