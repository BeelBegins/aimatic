# Governed AI assistant backend

Load the bench `ai-assistant-console` skill and only the relevant architecture
reference headings. Deterministic, permission-aware tools calculate facts;
the model explains them. Keep queries bounded, preserve provenance and test
summary/drill-through totals independently.

Never expose prompts, credentials, unrestricted SQL or cross-user/company/
branch data. Reproduce bugs at tool, assembly, API and UI layers in that order.
